main.go
package main

import (
    "github.com/naufalraism/aemeath"
    "log"
)

func main() {
    app := aemeath.New()

    // 1. Basic Route
    aemeath.GET(app, "/", func(c *aemeath.Ctx, _ struct{}) (string, error) {
        return "Hello Aemeath", nil
    })

    // 2. Type-Safe Route (Auto Validate JSON)
    aemeath.POST(app, "/user", func(c *aemeath.Ctx, in UserIn) (UserOut, error) {
        return UserOut{Message: "Hi, " + in.Name}, nil
    })

    // 3. Auto OpenAPI & TS Client Generation
    app.EnableDocs(aemeath.Info{Title: "Aemeath"})
    app.EnableClient()

    log.Fatal(app.Listen(":3000"))
}

Under the Hood

Zero Duplication

Your Go Structs are the single blueprint. From validation, TypeScript clients, to OpenAPI docs, Aemeath ensures everything stays perfectly in sync.

1. Request Validation

Aemeath validates the incoming JSON against your struct tags, ensuring only clean data reaches your handler.

type User struct { Name string \`validate:"required"\` }

2. Type Inference

The TypeScript client is automatically generated from your Go structs. No manual frontend typing required.

export interface User { name: string; }

3. OpenAPI Docs

Scalar OpenAPI documentation is generated automatically. Always accurate and up-to-date with your code.

app.EnableDocs(aemeath.Info{...})
