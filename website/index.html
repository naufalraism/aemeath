Why Aemeath

Engineered
for Go.

Aemeath was built to prove that Go doesn't have to be verbose. We bring the ergonomics of modern frameworks to plain, standard-library Go.

No hidden magic. Plain Go types and a thin layer over net/http that your IDE naturally understands.

Your handlers stay plain Go, the rest is generated.

Type-Safe

Zero manual parsing.

Auto TS Client

Frontend types included.

Same rules everywhere

One set of validation tags drives the server, OpenAPI, TypeScript and Zod.

Standard Library

The core has no third-party dependencies.

main.go
package main

import (
    "github.com/naufalraism/aemeath"
    "log"
)

type UserIn struct {
    Name string `json:"name" validate:"required"`
}

type UserOut struct {
    Message string `json:"message"`
}

func main() {
    app := aemeath.New()

    // 1. Basic Route
    aemeath.GET(app, "/", func(c *aemeath.Ctx, _ struct{}) (string, error) {
        return "Hello Aemeath", nil
    })

    // 2. Type-Safe Route (Auto Validate JSON)
    aemeath.POST(app, "/user", func(c *aemeath.Ctx, in UserIn) (UserOut, error) {
        return UserOut{Message: "Hi, " + in.Name}, nil
    })

    // 3. Auto OpenAPI & TS Client Generation
    app.EnableDocs(aemeath.Info{Title: "Aemeath"})
    app.EnableClient()

    log.Fatal(app.Listen(":3000"))
}

Features

                
Built for real projects. Designed for you.

                
Everything you need to build real APIs, without the cognitive overhead.

            

            

                

                    
🛡️

                    
End-to-End Type Safe

                    
Define your request and response structs once. Binding reads the path, query, headers, cookies, JSON and forms, and every validation failure comes back at once as a 422 with per-field errors.

                

                

                    
⚡

                    
Client Generator

                    
Generate a fully-typed TypeScript client, Zod schemas and React Query hooks directly from your Go structs. No more manual API typing.

                

                

                    
📖

                    
Auto OpenAPI

                    
Beautiful, interactive Scalar API documentation generated automatically from your code.

                

                

                    
🔌

                    
Plugin Ecosystem

                    
JWT, sessions, CSRF, OpenID Connect, PostgreSQL, MySQL, Redis, metrics and tracing. Each one is only compiled in when you import it.

                

                

                    
📡

                    
Realtime

                    
Server-Sent Events are in the core. WebSockets come as an optional package that accepts same-origin browser connections only.

                

                

                    
📂

                    
Static File Serving

                    
Serve a public folder with no directory listings. Your global middleware still applies to it.

Command line

                
From an empty folder 
to a running API.

                
Stop writing boilerplate. The Aemeath CLI creates projects from templates, scaffolds CRUD APIs, jobs and Dockerfiles, and rebuilds your server when files change, so you can focus on building features.

                
                
    
                    
  • 
                        
    
                            
                        
    
                        aemeath new - Start from the api, db or fullstack template. The db templates support SQLite, PostgreSQL and MySQL. The fullstack one adds a React + TypeScript app that uses the generated client.
                    
    • 
                    
  • 
                        
    
                            
                        
    
                        aemeath generate - Scaffold handlers, jobs, models, middleware, tests and a Dockerfile.
                    
    • 
                    
  • 
                        
    
                            
                        
    
                        aemeath dev - Rebuilds and restarts when files change, and can refresh your TypeScript files too.

Performance

                
A thin layer over net/http.

                
Time per request for one JSON route (lower is better). Aemeath adds typed binding and validation on top of the standard library for a small fixed cost.

                        1,126 ns/op

                        2,120 ns/op
                    

                    

                        

                    

                

                

                    

                        Gin
                        2,280 ns/op
                    

                    

                        

                    

                

                
Microbenchmark with httptest, median of five runs on an Intel i7-10750H (Windows, Go 1.27). Memory per request: net/http 1,040 B, Aemeath 1,152 B, Gin 1,433 B. Not a load test; results vary by machine. Reproduce with cd benchmarks && go test -bench . -benchmem -count 5 -benchtime 2s.

Security

      
Safe defaults, honest status.

      
Aemeath tries to make the secure choice the default one. You still own how you configure and deploy your app.

    

    

      
What the defaults do

        
    
          
  • JWT middleware rejects an empty secret, non-HMAC algorithms for secrets, and tokens without an expiry.
    • 
          
  • Sessions use random 43-character ids, never adopt an unknown id, and rotate the id at login with Renew.
    • 
          
  • WebSockets accept same-origin browser connections only.
    • 
          
  • CORS refuses to combine credentials with the * origin.
    • 
          
  • Static files never list directories; the in-memory session store is capped.
    • 
        

      
Pre-1.0, not independently audited

        
The code runs with the race detector, fuzzing and CodeQL in CI, but no outside team has reviewed it yet. There is no warranty, as the MIT licence says.

        
Found a problem? Please report it privately through GitHub instead of opening a public issue. Read the security policy
